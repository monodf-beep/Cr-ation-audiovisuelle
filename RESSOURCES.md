# Ressources — banques d'idées et outils

Ne pas réinventer : avant de concevoir un style, un mouvement ou un design sonore,
chercher d'abord dans ces banques.

## Méthode « style à la demande »

1. Franck décrit le style voulu (en quelques mots, une référence, une ambiance).
2. Recherche dans les banques ci-dessous + le web : 3 à 5 pistes pertinentes.
3. Pour chaque piste : nom, ce qui la caractérise, lien(s) vers des exemples réels,
   faisabilité, **et un aperçu réalisé sur nos propres images**.
4. Franck choisit ; on décline le style choisi sur tout le film.
